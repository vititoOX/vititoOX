## About me

I'm a DAM graduate focused on becoming a strong full-stack developer. I enjoy taking an application from the interface to the API and database, with special attention to maintainable code, useful validation and a professional user experience.

My current work is centered on strengthening backend and web-development fundamentals while building projects that can be run, tested and explained end to end.
