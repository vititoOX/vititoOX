## Featured project

### [NominaHub](https://github.com/vititoOX/NominaHub) — Payroll & HR management system

A full-stack ERP-style application for payroll and HR operations.

- REST API built with Flask and PostgreSQL, run with Docker.
- Role-based authentication using JWT and Angular HTTP interceptors.
- Payroll calculations using `Decimal` and PDF document generation with WeasyPrint and Jinja2.
- Angular 18 frontend with PrimeNG components.
